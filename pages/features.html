What you need

  • Browser: the current desktop version of Chrome, Edge, Firefox or Safari (the last two releases).
  • 3D: WebGL 2, which every browser above ships; the WebGPU demo additionally needs Chrome 113+ or Edge 113+.
  • Input: the studio is designed for a mouse and keyboard — drawing, dragging and orbiting use a pointer.
  • Screen: at least 1024 px wide for the studio; the suites, calculators and price book work on narrower windows.
  • Storage: projects and designs are saved in this browser's local storage, so clearing site data removes them — export a project to keep it.
